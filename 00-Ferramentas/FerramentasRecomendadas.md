# Ferramentas Recomendadas para Estudos AZ-104

Esta pasta serve como um guia para as ferramentas essenciais que complementam os estudos para a certificação AZ-104 Azure Administrator. As ferramentas listadas abaixo devem ser instaladas localmente em sua máquina.

## 1. Azure CLI (Command Line Interface)

*   **Descrição:** Ferramenta de linha de comando para gerenciar recursos do Azure de forma eficiente.
*   **Utilidade:** Essencial para automação, scripts e gerenciamento rápido de recursos sem o portal.
*   **Link para Download:** [Instalar a CLI do Azure](https://docs.microsoft.com/cli/azure/install-azure-cli)

## 2. Azure PowerShell

*   **Descrição:** Módulos PowerShell para interagir e gerenciar recursos do Azure.
*   **Utilidade:** Alternativa à CLI para quem prefere o ambiente PowerShell, especialmente para scripts mais complexos.
*   **Link para Download:** [Instalar o Azure PowerShell](https://docs.microsoft.com/powershell/azure/install-az-ps)

## 3. Microsoft Azure Storage Explorer

*   **Descrição:** Aplicativo de desktop para gerenciar visualmente os recursos de armazenamento do Azure (blobs, filas, tabelas, arquivos).
*   **Utilidade:** Facilita a visualização, upload, download e gerenciamento de dados em contas de armazenamento.
*   **Link para Download:** [Baixar o Azure Storage Explorer](https://azure.microsoft.com/features/storage-explorer/)

## 4. Docker Desktop

*   **Descrição:** Ambiente para construir, executar e gerenciar contêineres Docker localmente.
*   **Utilidade:** Fundamental para entender e testar aplicações conteinerizadas antes de implantá-las em serviços Azure como App Service, ACI ou AKS.
*   **Link para Download:** [Baixar o Docker Desktop](https://www.docker.com/products/docker-desktop/)

## 5. Visual Studio Code

*   **Descrição:** Editor de código-fonte leve, mas poderoso, com suporte a diversas linguagens e extensões.
*   **Utilidade:** Ideal para escrever scripts PowerShell, modelos ARM, código de aplicação e gerenciar arquivos do projeto.
*   **Link para Download:** [Baixar o Visual Studio Code](https://code.visualstudio.com/)

## 6. Git

*   **Descrição:** Sistema de controle de versão distribuído.
*   **Utilidade:** Essencial para rastrear mudanças no código, colaborar e gerenciar diferentes versões do seu projeto.
*   **Link para Download:** [Baixar o Git](https://git-scm.com/downloads)
